<Section number="02" title="THE PROBLEM">

A cashier and inventory system needed an interface that kept day-to-day transactions and stock information easy to navigate. Sales and inventory data also needed to be readable in dashboard form.

</Section>

<Section number="03" title="WHAT I BUILT">
<Decisions>

<Decision n="01" title="Type the interface">

Built the cashier and inventory interface with React and TypeScript, making the application data shapes explicit.

```text
typed data → React views → cashier workflow
```

</Decision>

<Decision n="02" title="Make operational data legible">

Used ECharts for sales and inventory dashboards, giving the system dedicated views for its operational data.

```text
sales + inventory → ECharts → dashboards
```

</Decision>

<Decision n="03" title="Connect the workflows">

Used Swiper navigation to move between the system's views while keeping the cashier and inventory experience cohesive.

```text
cashier ↔ inventory ↔ sales dashboard
```

</Decision>

</Decisions>
