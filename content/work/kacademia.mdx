<Section number="02" title="THE PROBLEM">

An online education platform needed to connect teachers and students through classes while keeping course data, authentication and communication in one coherent system. The AI tutor needed to answer from course material and help teachers generate questions.

</Section>

<Section number="03" title="WHAT I BUILT">
<Decisions>

<Decision n="01" title="Ground the tutor in course content">

Built a RAG tutor that retrieves course context before producing answers for students or questions for teachers. The retrieval step connects the response to the material being taught.

```text
course content → chunks → embeddings
→ retrieval → grounded answer
```

</Decision>

<Decision n="02" title="Model relationships explicitly">

Built a relational PostgreSQL schema with Prisma and deployed it on a cloud server. Typed access keeps the application aligned with its database model.

```text
application → Prisma → PostgreSQL
```

</Decision>

<Decision n="03" title="Protect the route boundary">

Used NextAuth with middleware route protection. Authentication is checked before protected platform routes are reached.

```text
request → middleware → session → protected route
```

</Decision>

<Decision n="04" title="Complete the account lifecycle">

Integrated transactional email through SMTP and Nodemailer for alerts, updates and password resets.

```text
account event → Nodemailer → SMTP → inbox
```

</Decision>

</Decisions>
</Section>
